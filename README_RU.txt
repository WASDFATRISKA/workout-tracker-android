WORKOUT TRACKER — СБОРКА APK БЕЗ UBUNTU И BIOS НА ТВОЁМ ПК

Важно: APK — это установочный файл Android. Обычный .py-файл Android напрямую не устанавливает.
Для превращения Python/Kivy-программы в APK нужен Android SDK/NDK. Их можно использовать на облачном
сервере GitHub Actions — поэтому на своём компьютере не нужно включать WSL, Ubuntu или BIOS.

КАК ПОЛУЧИТЬ APK:
1. Создай аккаунт на github.com (если его ещё нет).
2. Создай новый репозиторий (New repository), например workout-tracker.
3. Загрузи ВСЁ содержимое этой папки в корень репозитория, сохранив папку .github/workflows.
   Важно: загружай файлы и папку, а не ZIP целиком.
4. Открой репозиторий на GitHub → вкладка Actions.
5. Выбери "Build Android APK" → "Run workflow" → зелёную кнопку подтверждения.
6. Дождись завершения сборки. Первый запуск может занять 10–20 минут.
7. Внизу страницы сборки в разделе Artifacts скачай workout-tracker-apk.
8. Распакуй скачанный архив — внутри будет файл .apk.
9. Отправь APK на Android и открой его для установки. Если Android спросит разрешение,
   разреши установку для приложения, из которого открываешь APK.

Где искать файлы:
- main.py — приложение.
- buildozer.spec — настройки Android.
- .github/workflows/build.yml — автоматическая облачная сборка APK.

Данные приложения сохраняются локально на телефоне в SQLite. Синхронизации с компьютером нет.
